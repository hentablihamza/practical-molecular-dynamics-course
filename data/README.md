# Datasets

Everything in this folder is either an unmodified public record (PDB entries) or was generated by the scripts in
[`scripts/`](../scripts) with the settings recorded in [`provenance.json`](provenance.json). Nothing was edited by
hand. The precomputed trajectories exist so that the analysis notebooks run in seconds on Google Colab and in CI;
every notebook also shows how to produce the same kind of data live.

## `ligands/`: erlotinib parameters (notebook 11)

- `erlotinib_1M17_H.pdb`, `erlotinib_1M17_H.sdf`: erlotinib heavy atoms from PDB 1M17 (ligand AQ4), bond orders
  assigned from the SMILES `COCCOc1cc2ncnc(Nc3cccc(C#C)c3)c2cc1OCCOC` and hydrogens added with RDKit (neutral form).
- `erlotinib_gaff2.xml`: OpenMM force-field file with **GAFF 2.11** parameters and **AM1-BCC** partial charges, from
  `openmmforcefields` (`GAFFTemplateGenerator`) with AmberTools antechamber/sqm. Notebook 11 regenerates it live
  when the conda environment is available and uses this file otherwise (e.g. on Colab).

## `trajectories/`: precomputed simulations

Generated with [`scripts/generate_trajectories.py`](../scripts/generate_trajectories.py) (OpenMM, CPU platform).
Exact settings and seeds are in `provenance.json`.

| File(s) | System and protocol | Used in |
|---|---|---|
| `alanine_dipeptide_phi_psi.csv` | Alanine dipeptide, ff14SB + GB-OBC2 implicit solvent, 300 K Langevin, 2 fs, 4 independent replicas × 10 ns after 100 ps equilibration; φ/ψ every 1 ps (columns `replica,time_ps,phi_deg,psi_deg`). | 10 |
| `chignolin_protein.pdb`, `chignolin_rep{0,1,2}.dcd`, `chignolin_thermo.csv` | CLN025 (5AWL) prepared with PDBFixer at pH 7, ff14SB + TIP3P-FB, cubic box with 1.0 nm padding, 0.15 M NaCl. Minimization, 20 ps NVT + 20 ps NPT with heavy-atom restraints, then 3 independent **0.2 ns** NPT production runs (300 K, 1 bar, 4 fs with HMR, PME). Peptide coordinates every 2 ps (superposed on the first frame); thermodynamic log every 2 ps. | 08, 09, 12 |
| `egfr_erlotinib_complex.pdb`, `egfr_erlotinib.dcd` | EGFR kinase domain (1M17 residues 672–964) + erlotinib (GAFF2/AM1-BCC), ff14SB + TIP3P-FB, truncated octahedron with 1.0 nm padding, 0.15 M NaCl. Minimization, 15 ps NVT + 15 ps NPT with solute heavy-atom restraints, then **50 ps** NPT production (300 K, 1 bar, 4 fs with HMR, PME). Protein + ligand coordinates every 1 ps, superposed on protein Cα. | 11 |

These are deliberately **short** teaching trajectories. They are long enough to demonstrate every analysis, but not
to support research conclusions about these systems (Notebook 12 explains why).

## Regenerate

```bash
conda env create -f environment.yml && conda activate practical-molecular-dynamics-course
python scripts/fetch_structures.py                 # re-download the PDB entries
python scripts/generate_trajectories.py all        # ~1 h on an 8-core CPU; minutes on a GPU (OPENMM_PLATFORM=CUDA)
# longer runs: CHIGNOLIN_NS=1 EGFR_PS=500 python scripts/generate_trajectories.py chignolin egfr
```
